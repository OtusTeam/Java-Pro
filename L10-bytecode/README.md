# Байт код, ClassLoader, инструментация, ASM
**Курс:** Java pro
## Инструмент измерения времени выполнения
Аннотация [Measure](src/main/java/com/otus/annotation/Measure.java) должна позволить произвести замер времени выполнения метода, отмеченого ею.  
Пример показывает все, что необходимо для выполнения домашнего задания.  
### Два способа решения
#### Proxy API
**Точка входа:** [ProxyMeasureDemo](src/main/java/com/otus/proxy/ProxyMeasureDemo.java).  
Более простой вариант.  
Используя `java.lang.reflect.Proxy`, создаем прокси объект добавляя функционал замера времени выполнения.
Переопределив метод `invoke()` получаем возможность добавить кастомную логику как перед вызовом необходимого метода, так после.  
#### ASM библиотека
Более сложный вариант, через формирование байт-кода JVM.  
Обратить внимание на паттерн Visitor.  
Подключается в [pom.xml](pom.xml).  
**Точка входа:** [AsmMeasureDemo](src/main/java/com/otus/asm/AsmMeasureDemo.java).  
Начало ASM логики `cr.accept(new MeasureClassVisitor(cw), 0);`.  
Переопределение методов `visitCode` и `visitInsn` это наши точки 'А' и 'Б', позволяющие запомнить начало выполнения метода и его окончание.
